# Counter Atlas — คู่มือแก้ทาง Dota 2

เปิด index.html ด้วย Chrome หรือ Edge ได้ทันที ไม่ต้องติดตั้งแพ็กเกจหรือเปิดเซิร์ฟเวอร์

- ครบ 127 ฮีโร่ตามรายชื่อ OpenDota ที่ตรวจวันที่ 24 กันยายน 2026 รวม Kez และ Largo
- ทุกฮีโร่มีตัวเลือกแก้ทางอย่างน้อย 5 ตัว พร้อมวิธีรับมือและเงื่อนไขภาษาไทย รวม 635 คู่
- ค้นหาชื่อภาษาอังกฤษ ชื่อย่อ และชื่อไทยบางตัวที่มีอยู่ในข้อมูล
- ใส่ฮีโร่ฝั่งตรงข้าม 5 ช่อง และทีมเรา 5 ช่องตาม Carry / Mid / Offlane / Soft Support / Hard Support
- ช่องค้นหาฮีโร่มีรายการชื่อแนะนำตั้งแต่พิมพ์ตัวอักษรแรก เลือกจากรายการเพื่อลดการพิมพ์ชื่อผิด
- แนะนำตัวเลือกแก้ทางสำหรับตำแหน่งทีมเราที่ยังว่าง โดยตัดฮีโร่ที่ถูกเลือกไปแล้ว แสดงเหตุผลต่อศัตรูแต่ละตัว และกดเลือกลงช่องเพื่อคำนวณดราฟต์ต่อได้ทันที
- ใช้ Dota2ProTracker role grid 7.41f เป็นตัวเลือกตำแหน่งหลัก และบทบาททั่วไปของฮีโร่เป็นตัวเลือกเสริม; ไม่ใช่สถิติเลนสดและอาจเปลี่ยนตามแพตช์
- แสดงป้ายแหล่งที่มาหรือข้อวิเคราะห์กลไกในคู่แก้ทางแต่ละรายการ
- แสดงไอเทมที่ควรพิจารณาแก้ทางในหน้าฮีโร่และแยกตามศัตรูที่กรอกในตัวช่วยดราฟต์ พร้อมเหตุผล เงื่อนไขซื้อ และแนะแนวตำแหน่งผู้ซื้อจากไลน์อัปทีม โดยไม่จัดเป็น build บังคับ
- มีแผนที่ Ward 44 จุด กรองตามฝั่ง/โซน กดหมุดอ่านเหตุผล ลากแก้ตำแหน่ง เพิ่ม Ward เองพร้อมชื่อ/เหตุผล หรือเลือกลบ Sentry; การแก้ไขบันทึกในเบราว์เซอร์และคืนชุดเริ่มต้นได้
- กรอง Strength / Agility / Intelligence / Universal และกดชื่อคู่แก้ทางเพื่อดูจุดอ่อนของตัวนั้นต่อได้
- ใช้ปุ่มย้อนกลับของเบราว์เซอร์กลับไปฮีโร่ก่อนหน้าได้
- เปิดใช้ออฟไลน์ได้ ยกเว้นลิงก์อ้างอิง ไม่มีสถิติสดและไม่อัปเดตอัตโนมัติ

## ขอบเขตข้อมูล

ครบทุกฮีโร่ ไม่ได้หมายถึงครบทุกคู่แก้ทาง ทุกตัวมีตัวอย่างคู่ที่ควรพิจารณาอย่างน้อย 5 ตัว ไม่ใช่การจัดอันดับหรือการรับประกันชัยชนะ

อ้างอิงรายชื่อจาก https://api.opendota.com/api/heroes และคำแนะนำกลไกจากหน้า Counter ของ Dota Coach รายฮีโร่ มี URL และแพตช์ต่อหน้าใน sources.json
รายการไอเทมส่วนใหญ่เริ่มจาก Dota2Counters ซึ่งเป็นคำแนะนำชุมชนที่ไม่จัดอันดับ; Enigma, Largo, Primal Beast และ Skywrath Mage ใช้ตัวเลือกจาก Dota Coach. เหตุผลในหน้าเว็บสรุปกลไกและเงื่อนไขทั่วไปของไอเทม ไม่ใช่ build บังคับ
ในตัวช่วยดราฟต์ สรุปจำนวนฮีโร่ศัตรูที่แหล่งข้อมูลระบุไอเทมชิ้นเดียวกัน และเสนอ role ผู้ซื้อแบบกว้างจากตำแหน่งที่ทีมกรอก; ตัวเลขนี้ไม่ใช่สถิติอัตราชนะ และควรให้ผู้เล่นเช็กบิลด์กับตกลงผู้ซื้อเอง
ปุ่มแผนที่ Ward ใน sidebar เปิดภาพแผนที่ที่แนบมา; หมุดเป็นจุดแนะนำโดยประมาณ ไม่ใช่พิกัดวางจริง อ้างอิงแนวทาง Ward Recommendations 7.41e และ Ward Map 7.41f; ตำแหน่งควรตรวจเทียบกับแผนที่ในเกมและสถานการณ์จริง
แต่ละหน้าอ้างอิงอาจอยู่คนละแพตช์ ไม่กล่าวอ้างว่าเป็นข้อมูลสด ข้อควรระวังและช่วงเกมเป็นข้อวิเคราะห์ประกอบ

Largo ไม่มีคำอธิบายรายคู่ในหน้าอ้างอิง จึงแสดงตัวเลือก 5 ตัวเป็นข้อวิเคราะห์จากกลไก แยกจากข้อมูลสถิติของหน้าอ้างอิงอย่างชัดเจน

สำหรับเผยแพร่ผ่าน Git ให้ commit ไฟล์ `assets/dota-2-ward-map.png` ไปพร้อม `index.html`; ตำแหน่งที่ปรับในเบราว์เซอร์จะไม่กลายเป็นค่าเริ่มต้นของทุกคนจนกว่าจะคัดลอกชุด Ward สำหรับ Git มาบันทึกลงในโปรเจกต์

## ไฟล์

- index.html / styles.css / app.js: หน้าเว็บและการค้นหา
- assets/dota-2-ward-map.png: ภาพแผนที่พื้นหลังที่ผู้ใช้แนบ
- item-data.js: ไอเทมแก้ทางรายฮีโร่และคำอธิบายกลไก
- data.js: ข้อมูลภาษาไทยที่หน้าเว็บใช้งาน
- sources.json: รายการแหล่งข้อมูลและวันที่ตรวจ
- expansion-th.txt: วิธีใช้คู่แก้ทางที่เพิ่มเป็นภาษาไทย
- collect_sources.py: อ่านรายชื่อและคำแนะนำสาธารณะเพื่อใช้ตรวจทาน (ต้องเชื่อมต่ออินเทอร์เน็ต)
- build_five.py: ประกอบข้อมูลอย่างน้อย 5 ตัวเลือกต่อฮีโร่จากสรุปที่ตรวจทาน
- research/: บันทึกสำหรับตรวจทานและข้อมูลเดิมก่อนขยาย

การอัปเดตข้อมูลต้องตรวจคำแนะนำและแพตช์อีกครั้งก่อนประกอบ ไม่ควรรันตัวเก็บข้อมูลแล้วถือว่าสรุปภาษาไทยได้รับการอัปเดตตามแล้ว
